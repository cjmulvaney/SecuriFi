# SecuriFi™ Enterprise Login Portal

This is a web application that provides a highly secure login portal. It was originally a single HTML file and has been split into three separate files:

*   `index.html`: The main HTML file.
*   `style.css`: The CSS file for styling.
*   `script.js`: The JavaScript file for functionality.

## To run this web app

1. Clone this repository.
2. Open the `index.html` file in your web browser.
